# dotfiles

Managed using [chezmoi](https://chezmoi.io). The `main` branch contains chezmoi source files (prefixed with `dot_`, `private_`, etc.). The [`rendered`](../../tree/rendered) branch contains the actual rendered dotfiles as they would be applied to a machine.

## Rendered branch

The `rendered` branch is auto-generated by `render_macos_output.sh` whenever changes are pushed from `main`. Template variables use placeholder values and `Library/` is excluded.

To render manually:

```sh
./render_macos_output.sh
```

The following 2 files are in `main` branch for simplicity purpose. It is meant to be used only in the `rendered` branch:
- `_config.yml`
- `docs/*`

## Removing files

chezmoi doesn't delete a file on the target machine just because it was removed from the source. Deletions have to be listed explicitly in [`.chezmoiremove`](.chezmoiremove), or the file just lingers on every machine that already applied it.

Before trusting it, preview what it would actually remove:

```sh
chezmoi apply --dry-run --verbose
```

## Git hook setup (one-time)

```sh
git config core.hooksPath .githooks
```

This enables:
- **pre-push**: renders dotfiles to the `rendered` branch (see above).
- **pre-commit**: reminds you (non-blocking) to update `.chezmoiremove` whenever a commit deletes a file, so removals don't get missed on the next `chezmoi apply` elsewhere.
